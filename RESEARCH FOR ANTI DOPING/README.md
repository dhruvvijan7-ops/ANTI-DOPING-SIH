# Detailed Anti-Doping Intelligence Documentation Package

This package replaces the earlier brief specification with a substantially more detailed baseline.

Documents:
- 00_MASTER_SPECIFICATION.md — overall product definition and complete MVP scope
- 01_DETAILED_PRD.md — product requirements, user stories and traceability
- 02_DETAILED_ARCHITECTURE.md — architecture, modules, APIs and deployment
- 03_DATABASE_SCHEMA.md — database objects, fields, relationships and indexes
- 04_ALGORITHMS.md — detection, anomaly, correlation and risk algorithms
- 05_COMPETITIVE_RESEARCH.md — existing systems and differentiation
- 06_SECURITY_PRIVACY.md — threat model, RBAC, privacy and AI safety
- 07_TESTING_AND_DATA.md — synthetic dataset, test cases and evaluation
- 08_UI_UX_SPEC.md — screen-by-screen interface requirements
- 09_THREE_DAY_EXECUTION.md — hour-by-hour execution and demo plan
- 10_RESEARCH_AND_SOURCES.md — evidence register and primary sources

Important:
- This is a prototype specification, not a production NADO operational specification.
- Real personal/sensitive data must not be used.
- Risk scores are investigative prioritization signals, not guilt probabilities.
- 2027 WADA ISII material is treated as draft/future framework, not current binding standard.
